Infraestructura de Datos Espaciales

Código 12436 · Ingeniería Civil en Geomensura y Geomática
Resultado de aprendizaje general. Desarrollar una infraestructura de datos espaciales interoperable para una organización o ámbito territorial, mediante arquitectura de datos y servicios, metadatos y catálogo, publicación de servicios web y APIs geoespaciales, y procedimientos de seguridad, administración, monitoreo y consumo desde clientes SIG o web.
